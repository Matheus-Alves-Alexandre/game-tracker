# Contributing

Use English in code, documentation, issues and pull requests. Explain the user-visible behavior and provide proportionate tests. Follow the setup and commands in README.md.

Open a focused branch and pull request. All required checks must pass before merging. Do not bypass protection to fix a failing test. Include a reproduction when reporting a bug and remove private titles, paths, tokens and account details from logs.

Do not commit personal spreadsheets or databases. Use synthetic fixtures. Avoid adding dependencies for features that can be implemented simply with the existing stack. Preserve upstream licenses and notices when reusing code. Contributions are provided under AGPL-3.0-only.
